# 实验：同一篇原文，五个强度档

## 一、控制变量

| 项 | 设定 |
|---|---|
| 原文 | `tests/samples/ai_essay_2.md`（1076 字，论「数字孤独」） |
| 判据版本 | 当前 skill（SKILL.md + references 六份 + 词库 233 条） |
| 脚本 | `af.py scan` / `af.py metrics` / `af.py check`，各档同一版本 |
| 执行 | 五个子代理**并行且互不知情**，只拿到自己那一档的定义 |
| 变动量 | **只有强度档**（L0–L4） |

## 二、五档的操作定义

| 档 | 允许动 | 不许动 | 改完该是什么样 |
|---|---|---|---|
| **L0** 诊断 | 不动字 | 一切 | 一份报告 + 档位建议 |
| **L1** 轻扫 | 只删确定项（元话语、拔高、空转句、预告） | 句子结构、名词化、语序、段落 | 略短、更干净、骨架不变 |
| **L2** 标准 | 甲轴全面；乙轴只改可还原的名词化；丙轴只删元话语与拔高 | 结构、节奏、段落顺序、语域 | 骨架换成汉语，结构不动 |
| **L3** 重写 | 三轴全开，须自选语域（R5 科普 / R7 散文）并说明 | 观点、论据、事实；不得编造细节 | 语域明确、结构打散、节拍变宽 |
| **L4** 重铸 | 按指定人设重写，可改结构与叙述顺序 | 不得编造经历、不得声音挪用 | 读起来像另一个人写的同一件事 |

## 三、L4 的人设（本次无作者声音样本，故为限定模拟）

「一位不信任技术叙事的中年随笔作者」：
短句为主、句长参差大、爱用具体名词、不解释自己、结尾不收金句、可保留轻微不确定，但不许编造亲身经历。

**这不是作者本人的声音**，实验报告里须声明。

## 四、评估维度

| 维度 | 取法 | 看什么 |
|---|---|---|
| 字数变化 | chars 改前/改后 | 力度粗估 |
| 句长标准差 | `af.py metrics` | 是否变匀（丙轴核心） |
| 连词密度 | 同上 / 千词 | 甲轴是否真降 |
| 命中数 | `af.py scan` 全量，改前/改后 | 病灶是否真减 |
| 对账 | `af.py check` 七项 | 有无改坏（数字、模态、术语、节拍） |
| 自评 | 各档报告 | 有无过度去味、有无编造 |

## 五、预期（待验）

- L1 改动最少，命中数下降有限，节拍几乎不变。
- L2 甲轴命中显著下降，连词密度下降，句长标准差**不应变小**。
- L3 命中数大幅下降，但**节拍必须变宽**（sd 上升）；若不变宽，说明只是在删，没在重写。
- L4 节拍最宽，命中数可能不是最低——因为换声音不等于消病灶。

**最值得看的对照**：L3 与 L4 的 `af_check` 节拍项。若 L3 的 sd 比原文小，则「三轴全开」名不副实。
