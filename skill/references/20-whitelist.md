# 白名单、黑名单与灰区

> 本文件的用途：给判定流程装第一道闸。**白名单先于黑名单**——顺序错了，会把真人也在用的形式一并清掉，产出的中文反而不像中文。

## 一、为什么必须先过白名单

误伤的代价高于漏判。把「被评为」「数据的采集」「关于」当病灶删掉，读者立刻觉得「这人不会写中文」。

贺阳《现代汉语欧化语法现象研究》（商务印书馆 2008）后记的结论是硬边界：

> **汉语系统中并不存在真正的所谓「恶性欧化」现象。**

理由是「恶性」只在个人言语中昙花一现，进不了语言系统。这条直接决定：白名单不是妥协，是语言事实。

## 二、白名单：已入常态，不应再改

命中即放行，不进报告。

| 项目 | 合法化依据 | 此处才可动 |
|---|---|---|
| 他／她／它、它们 | 贺阳 3.1、3.3；今为唯一通行式 | 口语仍以「它」统称，不算错 |
| 关于／对于 | 贺阳 5.2 列为新兴介词；今为基本介词，无替代式 | 「关于……的问题」「对于……方面」是冗余框架 |
| 复合量词：人次、吨公里、秒立方米 | 贺阳 4.2.1；汉语无替代式 | 无 |
| 「之一」（限定集合） | 贺阳 4.2.3 | 无限定集合（「名著之一」「最有名的人物之一」）仍判病 |
| 术语位的性／化／度 | 壳测试不通过（无等价谓词），属构词资源 | 落到评价位、壳测试通过时判病 |
| 中性「被」：被评为、被列入、被依法、被称为 | 王力第四十四节已记为欧化破例；今法制新闻刚需 | 如意事且有更简主动式（被升为→升任）判病 |
| 「人们」 | 余光中 1987 判为「丑」，今在书面语中已无标记；替换为「大家」反降语域 | 与「大家」并存，语域不同，不构成错误 |
| 「当……时」 | 贺阳 5.4 论证「当」的连词化 | 「当……的时候」冗余，判病 |
| 学术公文的「N 的 V」与 12–20 字定语 | 贺阳第 2 章：定中结构「复苏和发展」，非新造 | 同一结构搬进散文即判病 |
| 判断句与系词「是」 | 王力第四十二节「主语和系词的增加」 | 回避「是／有」的伪动词（作为、设有、具备）判病 |
| 常规标点：单处解释性破折号、分号列举、引号首现、括号信息位 | 无实证，但汉语书面语已普遍如此 [经验] | 连环使用、防御性引号、句位括号判病 |

**判据的表述方式**：不写「含欧化成分」，写「无对价的偏离」。覆盖面不变，误伤率大降。

## 三、黑名单：仍是负担，可改

| 项目 | 为何是负担 | 例外 |
|---|---|---|
| 万能动词＋抽象名词（进行／作出／予以／加以，非固定搭配） | 动作一分为二，动词被架空 | 法律公文固定搭配：作出决定、予以驳回 |
| 伪术语（知名度、可读性、前瞻性、获得感、颗粒度、底层逻辑） | 无新增信息，只抬语域 | 确有定义的行业术语（「可解释性」在机器学习中有技术定义） |
| 抽象名词作主语（他的收入的减少……） | 施事被降为定语，句子失去动作 | 学术中确以过程为话题（「数据的采集分为三步」） |
| 「当……的时候」「在……的情况下」 | 介词框架拉长，重心后移 | 无，一律可缩为「……时」「……下」 |
| 「由于……使得」 | 句法错位：介词短语不能作主语 | 无，属硬错 |
| 长定语 ＞20 字前置 | 关闭句，读者须回读 | 法定全称、化学名、专利限定 |
| 零回指破坏（每句补主语） | 汉语靠省略承担指称，补足后句子散架 | 法律、合同、跨段换景 |
| 「们」用于非人／机构（民众们、听众们、制度们） | 伪复数，汉语以「众／诸／全体」承担 | 体育报道「球员们」已半常态化，属灰区 |
| 「如此……以至于」 | 翻译指示性结构 | 确需「程度—后果」强关联时，一篇一次为限 |
| 「作为一个……」 | 话题框架冗余，常与「我认为」叠加 | 确需限定身份视角时 |
| 逻辑标记四级堆叠（首先／其次／再次／最后） | 结构可预测，读者能猜下一段 | 长篇报告的导航 |
| 破折号连环 | 停顿被滥用，掩盖分句关系 | 单处解释 |
| 「之一」用于无限定集合 | 逻辑上削弱断言 | 集合明确（竹林七贤之一） |
| 防御性引号 | 术语未定义却处处设防 | 首现定义、反讽 |

**语料证据**：「如此……以至于」在译文用例中占 21.1%，台湾语料 0.00%，大陆作家 3.9%，网络 5.1%（伍勇进 2023）。译文约为大陆作家的五倍——这是「译文最容易过量」的直接证据，也是 R9 不能无限豁免的理由。

## 四、灰区：按文体与后果定档

| 项目 | 上档（可留） | 下档（该改） |
|---|---|---|
| 中性被动 | 新闻、法制、技术报告 | 散文、私人书信 |
| 「基于此」「就此而言」「值得注意的是」 | 学术论文、政策报告 | 科普、自媒体、消息 |
| 「有＋V」（有看到、有需要） | 口语转写、客服话术 | 书面正式体 |
| 「球员们」「员工们」 | 体育、企业内刊 | 文学、评论 |
| 段首主题句 | 新闻、教材、说明书 | 叙事、随笔 |
| 插入语（限定位） | 学术 | 散文 |

## 五、四条操作规则

1. **白名单前置。** 先查白名单，命中即放行。误伤的代价高于漏判。
2. **同类不叠加。** 同段最多报一条，不做加权计分。密度比条数更能说明问题，条数会诱导凑数。
3. **文体定阈值。** R1 学术、R2 公文：连接词、N 的 V、长定语阈值上浮；R7 文学、R8 私人：阈值下沉。依据是贺阳的语体结论 [实证]，不是品味。
4. **后果定力度。** 进档案的文本（论文、公文、合同）只改 C 类确定项，B 类保留并注明；一次性文本可放开到 B 类。不可逆场合力度降一档。

## 六、关于「欧化的收益」

只列病不列收益，判据体系必然过度纠偏。五四以来的欧化至少买到四样东西：

| 收益 | 不可替代性 |
|---|---|
| 复句精密化（句子延长，承载多层限定与嵌套命题） | 高。学术、法律、技术规范无此即无法表达 |
| 长句组织（树状结构补竹节结构之短） | 中。可用短句链替代，代价是层级关系模糊 |
| 被动中性化（「被」脱落遭受义） | 高。缺此则「某人被任命」只能说成「某人当上了」，客观性丢失 |
| 术语体系（类后缀使新概念可派生、可组合、可翻译） | 高。无词缀则每个新概念都要造一个不可分析的词 |

还有一项常被忽略：**形合对机器友好。** 显性连接词、主语、复数是可解析信号；全删掉，人读着舒服，机器读着糊涂。跨语言检索与机器翻译的场合，形合是资产。

反方也要承认：余光中与思果的担忧在**文学散文**里完全成立——欧化确实稀释了节奏、成语密度与省略之美。他们的错不在判断，在范围。

**结论**：欧化不是病，是**默认档整体上移**——书面语默认值从「短、动、隐」移到「长、静、显」。病不在用新档，在无论写什么都停在新档。
