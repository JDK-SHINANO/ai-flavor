# 对照实测：远程办公 / 数字孤独（2026-10）

本目录是 `humanize` 与 `ai-flavor` 新旧判据的隔离改写实测档案，对应项目 README 待办「新旧判据对照实测」的首轮两组。原始工作目录已归档，此处只留成品稿。

## 设计

两组共用同一套隔离措施：

- 子代理只允许读指定规则文件、写指定输出；`skill_view` / `skill_manage` / `terminal` / `web` / `memory` / `delegate_task` 一律禁用。
- XH 组读净化副本 `xh-rules-clean.md`（映射表与跨规则引用剥离，残留 ZH 计数 0）；ZH 组读原版 `catalog-zh.md`（本身不含 XH）。
- 日志核对：四个子代理均未调用 `skill_view`，未读规则文件以外内容。

## 结论（详见 `digital-loneliness/05-对照数据.md`）

1. 单跑 XH 最有效：抽象名词密度 24.3 → 9.0（−63%）；单跑 ZH 只到 22.2（−9%）。
2. 两轮不优于单轮，且顺序有偏：先 ZH 后 XH 只降到 16.4；先 XH 后 ZH 降到 13.8，但字数砍掉 35%。
3. 信息损失集中在限定与主张：三组删掉了「并非全盘否定技术价值」，只有单跑 XH 全保住。
4. 同一规则、不同执行：规则给的是探照灯，落刀仍在执行者。
