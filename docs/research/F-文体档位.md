# 文体档位：各场合的语言基线与人味容忍度

> ai-flavor 项目 F 档调研：为 R1–R9 提供可引用规范与可操作基线，使分档有据可依。
>
> 证据标记：【规范】有标准号或法规条文；【实证】有语料统计；【学理】有理论无中文量化；【经验】实践共识，**不得当数据引用**。

## 一、先把「有规范」和「无数据」分开

核查结果有一条要先纠正任务书的前提：**GB/T 9704-2012《党政机关公文格式》不管语言，只管格式**——用纸、版式、字体字号、层次序数、页码，全文无用词与句式条款。公文语言要求出自《党政机关公文处理工作条例》（中办发〔2012〕14 号），其第十一条只作转致：「公文使用的汉字、数字、外文字符、计量单位和标点符号等，按照有关国家标准和规定执行。」故公文的可引用链条是：条例给原则（第十九条）→ 转致国标（第十一条）→ 落到 GB/T 15834。**拿 9704 论证「公文不该用比喻」是引错了标准。**

九个档的规范覆盖极不均匀：

| 档 | 有成文规范 | 管到的层面 | 没管到的 |
|---|---|---|---|
| R1 学术 | GB/T 7713.2-2022、7713.1-2025 | 语种、规范汉字、标点、题名禁夸张词 | 句长、人称、名词化密度 |
| R2 公文 | 公文处理工作条例；9704（仅格式） | 准确简洁精练；层次序数；标点 | 名词、修辞、金句 |
| R3 技术 | 无国标；MS／Google 指南；阮一峰规范 | 句长、段落、被动、人称、比喻 | 无统计基线 |
| R4 新闻 | 新华社禁用词（行业规定） | 评价词、称谓、脏话 | 句长、结构 |
| R5–R9 | **无** | — | 全部 |

即：**只有 R1–R4 有可引用规范，R5–R9 全靠学理与经验。**这不是调研不足——规范只出现在有机构责任方的文体上（期刊、机关、厂商要对文本负责）；个人表达的文体没人写规范，学界只描写不规定。

### 1.1 规范原文（可直接引用）

| 出处 | 原文要点 | 对本体系的意义 |
|---|---|---|
| 公文条例第十九条（三） | 「内容简洁，主题突出，观点鲜明，结构严谨，表述准确，文字精练」 | 公文唯一成文语言标准，它**要求**「结构严谨」而非随意自然 |
| GB/T 7713.2-2022，5.1 | 「**遣词造句应符合汉语语法**」，标点符合 GB/T 15834 | **判「欧化过度」最硬的依据**：违反汉语语法的欧化即不合规 |
| 同上 4.3.1 | 正文「科学合理、客观真实、准确完整、层次清晰、逻辑严密、文字顺畅」 | 「客观真实」排抒情拔高，**不排**被动与名词化 |
| 同上 4.2.1 | 题名「不应使用广义术语、夸张词语等」，不宜超 25 字 | 硬条款，直接判「范式革命」类标题不合规 |
| 同上 4.3.5 | 致谢「语言宜诚恳、真挚、恰当」 | 学术文本**内部有语域分区**：正文客观，致谢可有人称与情感 |
| GB/T 9704-2012 | 层次序数「一、」「（一）」「1.」「（1）」，各层字体不同 | **公文列表是强制的**，用序数不用符号 |
| GB/T 15834-2011，5.1.4／5.1.5 | 破折号、省略号各「占两个字位置」 | 排版硬判据，可检出半角 `--`、`...` |
| 同上 4.10.3.8 | 破折号「标示事项列举分承」 | 破折号列举**合规**，不能见即删 |
| 同上 4.7.3.5 | 「一个句子内部一般不应套用冒号」 | 判「标题：内联说明」式密冒号 |
| 同上 B.1.4 | 「用分号隔开的几个并列分句不能由逗号统领或总结」 | 判分号层级错乱，可机器检出 |
| 同上 4.3.3.3 | 叹号「最多叠用三个」，「没有异常强烈的情感表达需要时不宜叠用」 | 国标**允许**叹号；「AI 不用叹号」是经验非规范 |
| 新华社禁用词慎用词（2019-07 修订）第 2 条 | 报道事实特别是产品、商品时「不使用『最佳』『最好』『最著名』『最先进』等具有极端评价色彩的词汇」 | 拔高的成文禁令，可外推到一切事实陈述 |
| 同上 第 5 条 | 领导活动「慎用『亲自』」；一般会议不用「隆重召开」 | 判公文与新闻的仪式性套语 |
| Microsoft 简体中文风格指南 2.1 | 用「类似于日常对话环境中的语言，而不是技术和商业内容中常用的正式、技术性语言」 | **技术文档正式度低于公文学术，是厂商写死的** |
| 同上 2.2.1 | 「使用第二人称代词『你』礼貌地询问用户」 | R3 用「你」，不用「用户」「您」 |
| 同上 2.1.4 | 「避免逐字直译」「严格的逐字直译会使语气生硬且不自然」 | 判 R3／R9 翻译腔 |
| Google 风格指南（Voice and tone；Second person） | Avoid "figurative language, which includes metaphors"；禁叹号、"please note"、"simply"、句首同构；用 you 代 we，祈使句执行动作 | **全部规范里最硬的反比喻条款**；人称要求与 Microsoft 独立同结论 |
| 阮一峰《中文技术文档的写作规范》 | 单句或逗号构件「20 个字以内」为佳，「20～29 可以接受」，30～39 须语义明确，「多于 40 个字，任何情况下都不能接受」；段落不超七行，最佳不超四行；不用被动；避免叹号 | **唯一给出句长与段落硬数字的中文技术文献**，性质为社区规范，非国标 |

阿里、腾讯未见公开的完整技术写作规范全文；业内实际引用的是上两家指南加阮一峰这一份。**记为「未找到」，不作补位。**

## 二、九档小档案

句长先讲口径。唯一可用大样本来自周义凯、刘海涛《现代汉语句长分布的普遍性和特殊性》（《外语教学与研究》2023 年 55 卷 5 期）：小说、新闻、社论、散文四体，整句平均句长 **20–25 词**，小说最短（近口语），新闻社论最长。【实证】三点限制须写明：单位是**词**非字（一词约 1.5 字，折 30–40 字，混用差一倍）；只覆盖四体，**其余六档无数据**；切分依句末点号。下文无数据处一律标【经验】。

### R1 学术论文

| 维度 | 取值 |
|---|---|
| 典型句长 | 长，常 40–70 字；限定成分多是长的主因 |
| 连接词容忍度 | 高：「因此」「然而」「就……而言」显性出现正常 |
| 名词化 | **高（正常）** |
| 第一人称 | 中：单数视学科，复数「我们」通行 |
| 口语词 | 极低，仅引语与举例 |
| 句末语气词 | 零 |
| 比喻与意象 | 低：功能性类比可，装饰性意象禁 |
| 加粗与列表 | 加粗限标题与术语首现；列表限方法、参数、材料 |
| 金句收尾 | **零容忍** |
| 段落长度 | 长段 200–400 字，一段一论点 |

依据：名词化与专业性正相关（Halliday 1998；朱永生《名词化、动词化与语法隐喻》，《外语教学与研究》2006 年第 2 期）【学理】；题名禁夸张词为硬条款【规范】；余为【经验】。国标未规定人称，学报投稿须知各有要求，未找到统一条文。

### R2 党政公文与工作汇报

| 维度 | 取值 |
|---|---|
| 典型句长 | 中长，多分句排比式 |
| 连接词容忍度 | **高**：「据此」「为此」「按照……要求」是体式标记 |
| 名词化 | **高（正常）**：「作出决定」「予以支持」 |
| 第一人称 | 机构自称「我部」「我市」正常；**个人「我」是缺陷** |
| 口语词 | 零容忍（引群众语须加引号） |
| 句末语气词 | 零 |
| 比喻与意象 | 零容忍；已词汇化的政治隐喻（抓手、瓶颈、底线）算术语 |
| 加粗与列表 | **列表强制**；**加粗无对应物**，靠字体字号分层 |
| 金句收尾 | 允许程式收束（特此通知），禁抒情金句 |
| 段落长度 | 100–250 字，一段一层次 |

依据：条例第十九条「结构严谨」、GB/T 9704 序数与字体、GB/T 15834 只有「着重号」（4.12）而无加粗，三项均为【规范】；余为【经验】。

### R3 技术文档与产品说明

| 维度 | 取值 |
|---|---|
| 典型句长 | **短**：目标 ≤20 字，20–29 可，>40 不接受；逗号长句 ≤100 字 |
| 连接词容忍度 | 中：步骤间「然后」可，句句「因此」是缺陷 |
| 名词化 | 中低：术语性名词化可，动作性（「进行配置操作」）是缺陷 |

| 口语词 | **可容忍至正常**，要求对话式 |
| 句末语气词 | 极低：「吧」可，「呢/啊」是缺陷 |
| 比喻与意象 | **明令禁止** |
| 加粗与列表 | **正常且常强制**：UI 元素加粗、步骤用列表 |

| 段落长度 | ≤7 行，最佳 ≤4 行 |

|---|---|

| 比喻与意象 | 消息体零容忍；通讯特写可，但不得含极端评价 |
| 加粗与列表 | 均禁 |

依据：句长【实证】周义凯、刘海涛 2023；评价词禁令【规范】新华社第 2 条；网络缩略禁令【规范】新华社第 9 条；其余【经验】。

## 三、特征 × 文体矩阵

○ 正常（默认值，删改反出错）／△ 可容忍（有边界，超限即缺陷）／× 明显是缺陷。下表判据为操作性转换，依据见第一、二节。

|---|---|---|---|---|---|---|---|---|---|
| 名词化 | ○ | ○ | △ | △ | △ | × | × | × | △ |
| 长定语 | △ | △ | × | × | △ | × | × | × | △ |
| 被动 | △ | ○ | × | △ | △ | × | × | × | △ |

### 3.1 判据一句话

| 特征 | ○与△的分界 |
|---|---|
| 名词化 | 动作能否找到动词位。○ 本身即术语（配置、折旧）；△ 能还原而不损精度（进行测试→测试）；× 口语里绝不这么说（进行一次进食） |
| 长定语 | 数「的」：一名词前三个以上「的」，或定语超 40 字，即缺陷 |
| 被动 | 施事测试：已知且重要却隐去＝缺陷；未知或不必说＝正常（样品被置于……） |
| 连接词显化 | 删掉是否会歧义。会＝保留；不会且只是提醒＝缺陷 |
| 第一人称 | 文本是否承担个人责任。承担＝正常；硬加（「我们认为」代无主句）＝缺陷 |
| 口语词 | 是否属说话人与听话人共享的语域。共享＝正常；跨语域借来装亲切＝缺陷 |
| 句末语气词 | 去掉后语气是否变硬且违作者意图。是＝该留；否＝多余 |
| 比喻 | 喻体是否提供源域没有的信息。提供＝正常；只把抽象词换成另一抽象词（如同一座桥梁）＝缺陷 |
| 三段式 | 第三项是否有增量。有＝正常；只是把前两项再概括一遍＝缺陷 |
| 金句 | 删掉是否损失事实或论证。损失＝留；不损失＝缺陷 |
| 列表化 | 各项是否同质同级。是＝正常；异质强并＝缺陷 |
| 加粗 | 对象是否界面元素或术语首现。是＝正常；是句中判断词（**关键在于**）＝缺陷 |

「删掉是否损失信息」是四条判据的共同内核（金句、三段式、连接词、名词化），可归为一句：**信息增量测试**。这一条能覆盖旧体系「正确的废话」全部子类。

### 3.2 格内差异补注

| 格 | 差异 |
|---|---|
| R2 金句 △ | 公文的「××具有重大意义」是**文种程式**非金句；判据改为「是否属该文种固定收束语」 |
| R2 比喻 × | 抓手、瓶颈、底线、闭环已词汇化，是术语。词典有独立义项则放过 |
| R3 口语词 ○ | 矩阵最反直觉的一格。技术文档正式度**低于**公文学术，是微软写死的，不是风格偏好 |
| R3 语气词 △ | 只放行「吧」（中文 UI 需缓和指令），「呢/啊」进正文即缺陷 |
| R5 名词化 △ | 上限由「是否紧随一句动词化解释」决定，不由密度决定 |
| R7 连接词 × | 只判书面连接词（因此、然而、与此同时）；「可是」「于是」属口语连接词，正常 |
| R8 列表化 △ | 事项清单正常；带「首先/其次/最后」的论述型列表是缺陷 |

## 四、标点：唯一有国标可依的部分

先分清两件事：**国标规定用法与位置，不规定频次。**故「破折号太多」无规范依据，只有统计与阅读经验；「破折号写成 `--`」「省略号写成 `...`」是明确违规。

| 现象 | 规范怎么说 | 判定 |
|---|---|---|
| `--` 或单破折号 | 形式「——」，占两字（4.10.2、5.1.4） | 违规，可机器检出 |
| 一句两个以上破折号 | 4.10.3.2 允许破折号作插入语，与逗号同功能；**无频次限制** | **无规范依据**，旧体系「破折号连环」应降级为风格建议 |
| 破折号列举 | 4.10.3.8 明确允许「标示事项列举分承」 | **合规**。R5/R6 正常；R2 中与 9704 序数体式冲突，实务仍用序数 |
| `...` 或 `。。。` | 省略号「……」六连点，占两字（4.11.2、5.1.5） | 违规，可机器检出 |
| 省略号＋「等」 | 国标未禁，公文实务普遍判重复 | 【经验】，非国标 |
| 句内套冒号 | 4.7.3.5「一般不应套用冒号」 | 违规。AI 的「**要点：** 说明」在 R1/R2 不合规 |
| 分号层级错乱 | B.1.4 分号并列分句不得由逗号统领 | 违规，可机器检出 |
| 加粗 | GB/T 15834 只有「着重号」（4.12），**无加粗** | 加粗是媒介特征，不在国标体系内，只靠【经验】判，须分媒介 |

对分档表很关键的一点：**标点判据可做硬规则（正则可捕获），修辞判据只能做软提示**。混报会让人以为「破折号连环」与「`--`」同等严重，而前者只是口味。

## 五、跨档位会失效的判据

旧体系（humanize 的 XH／ZH 目录）的检查点多在散文与一般写作上归纳，套到别档会反向出错。

| 旧判据 | 失效档 | 为什么 | 应改成 |
|---|---|---|---|
| 删四字格（ZH 29） | **R2**、R1、R4 | 公文四字格（统筹推进、压实责任）是体式与政治语汇，删了反不像公文 | 只在 R5–R8 判；R2 只判三连以上且无增量 |
| 去被动（ZH 28） | **R2、R9**、R1 | 规范性文件大量用受事主语句，因施事不必或不能指明 | 改为施事测试 |
| 去名词化（XH 1–8） | **R1**、R2、R9 | 名词化是学术公文语体的构成要素，与专业性正相关；R9 抽象层级由原作者选 | 分档阈值，R1/R2 只判「可还原且无精度损失」者 |
| 删显性连接（XH 16–23） | **R1、R2、R5、R9** | 意合是散文与消息的默认，非所有文体的默认；R9 删连词会丢源文逻辑 | 改为「删后是否歧义」测试 |
| 「无第一人称＝客观」 | **R5–R8 全部反向** | 这四档「没有我」才是缺陷；旧判据只在 R2（机构文）与 R4（记者不入文）成立 | 从「AI 痕迹」改为「文体特征」，判据换成责任承担 |
| 「语气词＝不专业」 | **R6、R7、R8 反向**、R3 | 自媒体与私信里零语气词是最强机器信号 | 只在 R1/R2/R4 判零容忍 |
| 「禁比喻」 | **R7、R5 反向**、R6 | 比喻是散文与科普的主业；Google 禁比喻**只适用技术文档**，被泛化成通例 | 判据改为「喻体是否带来新信息」，按档开关 |
| 「破折号连环＝AI」 | **R2、R5、R6** | 4.10.3.8 允许列举分承，频次无规范 | 降级为 R1/R3 风格建议；R2 改判「是否与序数体式冲突」 |
| 「列表化＝AI」 | **R2、R3 反向** | 公文序数强制，技术步骤必须列表 | 只在 R7 判缺陷；R5/R6 判「是否异质并列」 |
| 「加粗＝AI」 | **R3 反向** | UI 元素加粗是规范写法；公文根本不用加粗 | 只看 R6/R7；R3 只判句中判断词加粗 |
| 「长短句交错才自然」 | **R3、R4** | R3 有 40 字硬上限，要的是**一致的短**，交错反而违规 | 节奏判据只留 R5/R6/R7；R3 用上限，R4 用短句倾向 |
| 「金句收尾＝AI」 | **R2 部分**、R6 | 公文收束是文种程式；自媒体收尾是流量体式 | R2 改判是否为该文种固定语；R6 改判密度 |
| 「密度超阈值＝缺陷」 | **R1、R2** | 旧阈值（散文 5、公文 11–20/千字）已含分档雏形，但上限 20 对学术偏低 | 必须分档给；R1 上限**无数据，只给区间假设** |

**可操作结论：旧体系 59 条检查点里至少 13 条需要带文体开关。**不带开关直跑，在 R2 与 R7 上会出现方向相反的误判——同一段文字，在公文里被判「名词化过度」，在散文里被判「不够凝练」。这正是本项目要解决的。

## 六、R8：私人书信与即时消息

查证结果：无国标、无行业规定、无机构风格指南。GB/T 15834 的适用范围写「汉语的书面语」，字面覆盖即时消息，但它只管标点形式，不涉语域，且无强制力。实际语用中即时消息系统性偏离标点规范（省句末标点、换行代句号、`~` 代缓和、叹号超三个），这一偏离不构成错误，因为**该媒介的读者不按出版标准解读**。故 R8 判据只能建于语用学与语料观察，全标【学理】或【经验】。

**面子理论**（Brown & Levinson, 1987）：交际普遍构成面子威胁行为（FTA）。积极面子是被认可的需要，消极面子是不被打扰的需要。即时消息**同时威胁两者**：发消息打断对方＝威胁消极面子；已读不回＝威胁自己的积极面子。这解释了三类在别处是废话、在 R8 必需的现象：（1）**开场铺垫**（「在吗」「问个事」）是消极面子的补偿，旧体系「删预告句」在此失效；（2）**自我贬抑**（「我可能理解错了」）是积极面子的防御投资；（3）**回声重复**（复述对方用词再回应）是求同策略的语言实现。

**礼貌原则**（Leech, 1983）：策略、宽宏、赞扬、谦虚、一致、同情六准则。即时消息最活跃的是**一致准则**——先「嗯嗯」再提异议是常态，不是优柔寡断。

**汉语礼貌五准则**（顾曰国《礼貌、语用与文化》，《外语教学与研究》1992 年第 4 期，10–17 页）：贬己尊人、称呼、文雅、求同、德言行，其中贬己尊人是汉文化最突出特征。这决定两条判据：**称呼语不可省**，**自谦不是虚伪**。需与 AI 的「希望这对你有帮助」区分：后者是**服务性收尾**（service closing），来自客服语域，威胁的是关系对等而非礼貌程度。

| 现象 | 正常形态 | AI 味形态 | 判据 |
|---|---|---|---|
| 句长 | 一句一义，换行代句号 | 每句 30 字以上且结构完整 | 均值 >25 字即可疑 |
| 标点 | 常省句末，空行断句 | 标点齐全、句句「。」 | **标点过分齐全**是机器信号 |
| 语气词 | 「啊/吧/呢/了/哈」高频，「哈哈哈」独立成回合 | 零语气词 | 连续三条无语气词即可疑 |
| 连接词 | 零标记或「所以」「但是」 | 「因此」「然而」「此外」「综上」 | 出现任一书面连接词即可疑 |
| 完整度 | 主语省略、成分残缺、口误不修 | 主谓宾齐全、无冗余 | **语法过分完整**是机器信号 |
| 分段 | 1–2 句一段，长短不齐 | 段段等长，三点成段 | 段长方差小即可疑 |
| 收尾 | 无收尾，或突然中断 | 「希望这对你有帮助」「祝好」＋总结 | 出现总结句即可疑 |
| 称呼 | 有称呼语，随关系变化 | 无称呼，直接入题 | 缺称呼即可疑 |
| 比喻 | 生活化、就地取材 | 喻体来自宇宙／海洋／齿轮／桥梁类通用库 | — |

**R8 最可靠的一条判据**：AI 写不出「不完整」。私信特征大量来自省力原则与实时性——省略、修正、重复、突然中断都是时间压力的产物。任何结构完整、标点齐全、逻辑闭环的「私信」，用词再口语也不是真的。

## 七、结论

1. **规范只覆盖四档，且覆盖的是边缘。**R1–R4 有法可依，但管的是语种、标点、称谓、评价词——都是**可枚举项**；真正决定「像不像人写的」的句长、名词化密度、节奏，国标都没管。骨架必须由【经验】承担，规范只作底线校验。
2. **有数据的只有句长，且只有四档。**周义凯、刘海涛（2023）是唯一可用于校准的实证数字。连接词密度、名词化密度、语气词频率的分档阈值**全部无公开数据**，旧 skill 那两个阈值（散文 5、公文 11–20）亦属自订。
3. **跨档失效是系统性风险。**同一段文字会因假设文体不同而得到相反判断，R2 与 R7 的语言默认值几乎相反，是误判高发区。

由此得最小可用方案：**硬规则只放标点与可枚举词表（有国标或行业规定支撑），软提示放修辞与结构（带文体开关），阈值只给区间不给单值（标注未测定）。**三层分开实施，比追求一张统一分数表更站得住。

**未找到（明确记录）**：阿里、腾讯公开的完整中文技术写作规范；任何国标对各文体句长、连接词密度、名词化密度的分档规定；任何针对 R5–R8 的写作规范文献；关于「AI 文本句长方差小于人类」的中文实证研究。
