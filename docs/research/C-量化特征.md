# C｜LLM 文本的量化语言特征：可自动计数的指标、基线与失效条件

> 版本 v0.1 ｜ 2026-10-27 ｜ 定位：给「AI 味」判定提供可复现的计数口径，替代「凭感觉」。
> 标注约定：**[实证]** = 有论文数据表可查；**[学理]** = 由机制或理论推出，未直接测；**[经验]** = 工程/个人观察，未见系统数据。
> 凡本文写「未找到」的格子，都是查过的：不是懒得查，是查不到。

---

## 0. 一句话结论

1. **中文侧真正有实证支撑、且方向稳定的强指标只有三个**：连词密度（AI 2.77×）、语气词密度（人类是 AI 的 5.3×）、并列短语数（5.66×）、NP 长度（1.19×）**[实证]**。其余为弱指标。
2. **句长均值几乎不判别，句长方差判别**。中文句长均值人类 40.9 字 vs GPT 42.4 字（差 4%），而句长标准差（按字例）15.15 vs 12.84、按词例 9.25 vs 6.73（差 37%）**[实证]**。凡是只报「平均句长」的说法，等于没报。
3. **「em dash 是 AI 强信号」只在英文成立，且 2026 年已部分失效**；中文里没有一个标点可以对位替代它——中文标点总密度人类 0.135 vs GPT 0.136，几乎完全重合 **[实证]**。
4. **所有基线都是「模型版本 + 语域」的函数**。中文实证来自 GPT-3.5（2023 收稿），英文实证来自 GPT-4o / Llama 3（2024）。拿它们判 2026 年的模型，只能当量级参考，不能当阈值。
5. **元话语（「值得注意的是」「总的来说」）没有任何公开的中文实证频次**。这是最常被引用、却最缺数据的一条 **[实证缺口]**。本文给测量规程，不给编造的基线。

## 1. 读表约定：四层指标与可信度定义

按计算成本分四层——它决定了这套体系能走多远：

| 层 | 需要什么 | 典型指标 | 能否写进轻量脚本 |
|---|---|---|---|
| **A** | 正则/词典 + 分词 | 标点、套话、连词、语气词、代词、TTR | 能，纯 Python |
| **B** | 分词 + 词性标注 | 连词/介词/叹词密度（严格版）、词汇密度、MTLD | 能，需 jieba/HanLP |
| **C** | 句法分析器 | 名词短语长度、依存距离、句法树高 | 能，需 HanLP/LTP，慢 |
| **D** | 语义/语用标注 | 元话语功能、hedging 强度、回指链 | 只半自动，需人工校验 |

**可信度分级**（本文自定，用于判断「敢不敢写进判据」）：

- **高**：≥1000 篇、均值+标准差齐备、有显著性检验、同一研究内人机可比。
- **中**：有数字但样本小、口径不透明、二手转述，或原文自相矛盾。
- **低**：单一案例、厂商自述、媒体转述、无对照。

**结论 [学理]**：**「em dash 在中文里对应什么」这个问题本身就是错的。** em dash 是英文排版层的产物，中文排版传统里没有它的位置，所以它承载不了同样的信息量。中文把「连接显化」的负担压在了**连词、介词、定语链**上——这也解释了为什么中文连词密度的效应量（2.77×）比英文 conjuncts 的效应大得多。要做中文检测，**不要去找「中文的 em dash」，要直接测连词与定语链**。

**但有一个反向警告 [实证]**：Pew 数据显示 em dash 在真实网页里正在被人类模仿（2025 年半年内从 6.3 涨到 8.58/万词）；2026 年《经济学人》用 5.59 万句、120 万词做的对照发现，**em dash 已不再是可靠标记，四个模型里只有 Claude 用得比人类多**，更可靠的信号反而变成了「标点更少、逗号分号括号都用得少、句子更长、and 滥用」。**任何基于单一符号的判据都有半衰期。**

## 4. 失效条件：哪几个指标会在哪种文本上骗你

这一节是本文最该被认真读的部分。指标不是「对/错」，是「在什么条件下失效」。

### 4.1 短文本（< 1000 字 / < 500 词）

| 受影响指标 | 机制 | 证据 |
|---|---|---|
| **TTR / STTR** | TTR 随长度单调下降，短文天然虚高 | JCIP 明确因长度影响而改用 Log/Root/Uber/Corrected 四族；MUÑOZ 改用 1000 词分段 STTR **[实证]** |
| **MTLD** | 短文下因子数趋近 0，结果爆炸 | 本机实测：553 词样本 MTLD=339.6、18734 词样本 MTLD=485.0（后者为近代白话，分词失配叠加），而 6978 词的现代学术样本 MTLD=57.1。**< 1000 词不要报 MTLD** **[实证·本机]** |
| **句长方差** | 句数 <15 时标准差极不稳定 | 本机：889 字 / 14 句样本，句长 SD=65.7、CV=1.035（含列表项），完全不可用 **[实证·本机]** |
| **元话语密度** | 分母小，一次出现即拉高 | 逻辑推演 **[学理]** |
| **一切分类器** | OpenAI 官方声明 <1000 字符不适用；其分类器仅 26% TPR @ 9% FPR | OPENAI **[实证]** |

**处置**：正文 <1000 字时只输出「疑似/未发现」两档，禁止打分；指标层只保留**连词/介词/语气词密度**（比率型，小样本相对稳）与**标点计数**。

### 4.2 专业术语密集文本（论文摘要、法规、技术手册）

| 受影响指标 | 偏差方向 | 说明 |
|---|---|---|
| TTR / MTLD | **虚高**（被误判为「人类」） | 术语多为一次性词形，抬高词形数。英文侧 MUÑOZ 的人类新闻语料 NOUN 已占 19.69%，技术文本更高 **[学理]** |
| 元话语密度 | **虚低**（被误判为「AI」） | 「值得注意的是」在法规里近乎为零，但法规不是 AI 写的 **[经验]** |
| 连词密度 | 双向失真 | 学术写作本就高连词（本机学术样本 27.8/千词，高于 JCIP 人类问答的 13.0/千词），基线必须按语域取 **[实证·本机]** |
| 名词短语长度 | 虚高 | 术语本身即长 NP，与 AI 的「定语堆叠」混淆 **[学理]** |
| hedging | 虚低 | 严谨文本刻意少用模糊限制语 **[学理]** |

**处置**：**必须用同语域人类基线做分母**。REINHART 的做法值得照抄：把「人类第 2 段」与「LLM 同风格续写的第 2 段」配对比较，控住语域再比特征。

### 4.3 翻译文本

| 受影响指标 | 偏差方向 | 证据 |
|---|---|---|
| 连词 / 介词密度 | **双向上浮**（人译与机译都高，方向一致但幅度不同） | 翻译共性之「显化」（explicitation，Baker 1993）**[学理+实证]** |
| 名词短语长度 | 上浮（源语透射） | 沈梦菲、黄伟 2024：NMT 处理英汉长句倾向保留源语结构 **[实证]** |
| em dash | **在译文中被放大**：GPT 译文 27.3/千 token（PT）、25.3（ES），远高于其原文条件 | RESENDE **[实证]** |
| 句长 | 受源语支配，而非受生成者支配 | RESENDE：EN 人工译文 17.8 词 vs GPT 译文 16.9 词，差异被源语长度淹没 **[实证]** |
| 抽象度 | **去抽象化**（AI 把抽象表达换成具体说法） | WU：D5 维度 SMD = −0.42，p<0.0001；而人工译文与原创无差异 **[实证]** |
| 信息性 | **超信息性**（AI 译文比人工译文更信息密集） | WU：D1 维度 LLMT SMD = −0.31，HT 仅 −0.07 **[实证]** |
| 客观化 | 两者皆降主观性，AI 与人工**趋同** | WU：D4 维度 HT −0.20、LLMT −0.25 **[实证]** |

**这条最关键 [实证]**：WU 的三百万词语料显示，**LLMT 不是「更像机器」，而是三种倾向的特定组合——超信息、客观化、去抽象**。翻译体裁下，「连词多、NP 长」既可能是 AI，也可能是**合格的翻译**。判据必须允许「有对价」。

### 4.4 口语转录（访谈、会议记录、播客）

| 受影响指标 | 偏差方向 | 说明 |
|---|---|---|
| 叹词 / 语气词 | **人类侧极高**，指标「永远判人类」 | JCIP 人类问答 0.016 已显著高于 AI，口语只会更高；具体口语基线**未找到** |
| 句长方差 | 人类侧极大（片段、重复、修正） | 口语无标点，句界需靠停顿/标点恢复，误差大 **[学理]** |
| 平均依存距离 | 人类侧**更短**（口语少长定语） | JCIP 人类 3.900 vs AI 3.659 的差距可能被口语进一步拉大到「人类更短」，从而**翻转方向** **[学理]** |
| 重复性 | 人类侧极高（口头重复） | JCIP 相邻句实词重复 AI 0.831 / 人类 0.481；口语里人类会超过 AI，**方向翻转** **[学理]** |
| TTR | 虚低 | 口语词汇重复多 **[学理]** |

**处置**：口语转录**整表停用**，只留「叹词/语气词密度」，仅用于确认人类口语，不可反向判 AI。

### 4.5 四个共同的上位失效条件

1. **模型版本失效**：JCIP 用 GPT-3.5（2023 收稿）、REINHART 用 GPT-4o/Llama 3、RESENDE 用 GPT-4o，**无一覆盖 2025–2026 前沿模型**；em dash 数据在 2026 年已被推翻一半。阈值必须附「测于何模型、何日期」。
2. **指令失效**：REINHART 证明差异主要来自**指令微调**——Llama 3 base 的特征率接近人类，instruct 版才偏离。指纹是**对齐过程的产物**，一句「不要用破折号」就能削掉一个强指标 **[实证]**。
3. **提示词失效**：WU 明确承认产出取决于提示语设置，其语料用固定提示控制可比性。
4. **语言失效**：OpenAI 官方称非英语不可靠；中文基线只有 JCIP 一份，**无独立复现**——单点故障。

## 5. 商用检测器披露了什么，与学术指标重合在哪、分歧在哪

### 表 5　三家公开口径

| 检测器 | 公开披露的方法 | 性能自述/第三方 | 与学术指标的关系 |
|---|---|---|---|
| **GPTZero** | 2023 年 1 月版：**perplexity + burstiness**（困惑度 + 突发性）。官方明确：2023 年秋起改用深度学习架构，但**困惑度仍是其「七个指标」之一** | 未公开 FPR/TPR 曲线 | **burstiness ≈ 句长方差**，与 JCIP 的句长标准差、MUÑOZ 的分布离散度**同源**；perplexity 是学术指标表里**没有**的一项（词表外的概率量） |
| **Pangram** | 明确**否认**使用 perplexity/burstiness；自称神经网络分类器，用「最难分类文档的合成镜像」训练 + 主动学习迭代 | 2026 年第三方对比（硕士论文，n 有限）：完全 AI 论文上 Pangram 中位数最接近真值；完全人类论文上 Turnitin/Copyleaks/Pangram 均 0% 误报，GPTZero 有少量误报 | **拒绝可解释特征**，与本文的「可计数」路线正交。它证明：黑箱做得更好，但**不能告诉你为什么** |
| **OpenAI AI Text Classifier**（2023-01-31 发布） | fine-tuned GPT，端到端 | **英文 26% TPR @ 9% FPR**；官方声明 <1000 字符、非英语、公式化内容（如素数表）不可靠；易被改写绕过 | 无特征披露，纯黑箱 |

### 5.1 重合

- **句长方差 / burstiness**：GPTZero 的「burstiness」与学术侧的「句长标准差」是同一个量的两种叫法。这是**唯一一个商业与学术双方都认的指标** **[实证+厂商自述]**。

### 5.2 分歧（三处）

1. **标点**：学术侧把 em dash 当强特征（RESENDE 称其为数据集里**最具判别力的单一特征**），商业侧**从不公开以标点为判据**。原因很可能是符号规则太容易被规避（一次全局替换即可清零）。
2. **可解释性**：学术指标的价值不在准确率，在**可指认**——你能指着某句说「这里连词密度是 3 倍」。检测器只能给一个数。改稿用指标，判定用黑箱。
3. **口径漂移**：Pangram 批评 perplexity/burstiness 会**系统性不利于非母语写作者**（词汇量小、句式简单 → 天然低困惑度）。这与学术侧的失效条件（§4.2、§4.3）同源：**所有指标都在惩罚「规整」，而规整既可能是 AI，也可能是非母语、术语密集、翻译或公文。**

## 6. 没有出处的指标怎么自建（测量规程）

**原则：宁可标「缺口」，不写「大约 0.3」。** 以下四项是本文确认的缺口，附可执行方案。

### 6.1 通用规程（所有自建基线共用）

1. **分层抽样**：文体（学术/公文/技术/新闻/科普/散文/私人消息）× 时间（2022-11 前 vs 后）。每格 ≥100 篇，每篇 ≥1000 字；不足则只报区间，不报均值。
2. **人类样本的可证性**：优先取 2022-11 之前发表、或有写作过程证据（手稿、修订记录）的文本。**这是整个测量最容易作弊的一步**——2024 年以后的「人类文本」可能已被 AI 润色。
3. **AI 样本**：固定 prompt 集（≥20 题） × 每模型 5 seeds × temperature 0.7 与 1.0 两档；**记录模型版本号与日期**，写进语料元数据。跨版本不可合并。
4. **计算一致性**：同一分词器（jieba/HanLP 版本）、同一词典文件（**版本化，改词典即改基线**）、同一句界规则（含后置引号与括号）。
5. **统计**：报均值 ± SD + bootstrap 95% CI；报 Cohen's d；用混合效应模型以「文体」为随机效应（照 WU 的做法）。
6. **判别力验证**：单指标 AUC → 组合 logistic 回归 → 在 **FPR 固定 1%** 下报 TPR。不要只报准确率（JCIP 的 97.27% 是在人机各半的平衡集上取得的，真实场景远达不到）。

### 6.2 「句末语气词占比」缺口

- **现状**：JCIP 只报了语气词**密度**（0.016 vs 0.003），没报「含语气词的句子占比」，更没报「啊/呢/吧/嘛/罢了/就是了」的分项。
- **方案**：正则在句末（去尾引号后）匹配 `啊|呀|呢|吧|嘛|啦|咯|呗|哇|罢了|就是了|而已|着呢|来着`；同时用词性标注交叉验证，排除「啊」作叹词的情形。报两个数：句末语气词句占比、每千句语气词数。
- **为什么值得做**：语气词是目前效应量最大（5.3×）的中文指标，且难以被指令规避。

### 6.3 「元话语」缺口（最要紧的一个）

- **现状**：中文「值得注意的是/需要指出的是/总的来说/综上所述」**没有任何公开发表的频次基线**。英文侧只有间接证据（YANG：框架标记语 9.27 vs 2.59；J&H：ChatGPT 互动元话语更低）。
- **方案**：
  1. 建**封闭词表**（建议 15–30 条，含「值得注意的是/需要指出的是/不难看出/由此可见/总的来说/综上所述/换言之/首先其次最后/与此同时」），词表进版本控制。
  2. 按 Hyland (2005) 的 interactive / interactional 二分**分别统计**——因为英文证据显示二者方向相反（框架标记 AI 高、互动标记 AI 低），合成一个总数会把信号抵消掉。
  3. 单位用**每万字符**（不是每千词），避免分词差异污染。
  4. 分文体测：公文与学术的人类基线本身很高，跨文体不可比。
- **本机初测（仅示意，非基线）**：学术论文正文 4.0 处/万字符；内部技术文档 0.0 处/万字符。**两个人类样本差 4 倍**——再次说明语域主导。

### 6.4 「中文过度词表」缺口

- **现状**：英文有完整清单（tapestry 出现在 23% 的 GPT-4o 输出里、amidst 27%；camaraderie 162×、intricate 119×）**[实证]**。中文**没有对应研究**。
- **方案**：照 Pew 的做法，取大规模中文网页语料做**前后对比**（2022 vs 2025 词频比值），比值 >3 且绝对频次 >1/万词的进候选表。这比「凭印象列 AI 词」可靠。**注意**：该法捕捉的是「AI 输出 + 人类模仿」的合力，要区分需再在受控生成语料上验证模型是否真的偏好该词。
