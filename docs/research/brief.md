# 项目：AI 味的解构与分档去除（工作代号 ai-flavor）

## 一、目标

为中文（兼顾英文）书面文本建立一套**可判定、可分档、可推荐**的「AI 味」识别与去除体系，最终产物是一个新的 Hermes skill：

1. 把「AI 味」从印象拆成可计数、可指认的语言学特征；
2. 按**文体 / 场合 / 读者 / 后果**分档，给出各档的容忍度与基线；
3. 由 AI 读文本与情境后**推荐**一档组合，并说明理由；
4. 每条判据尽量有实证来源，区分「实测数据」与「学理推断」。

## 二、现有基础

- 旧 skill：`~/.hermes/skills/creative/humanize/`（SKILL.md + references/ 五份目录 + 三个脚本）。
  - `references/catalog-xh.md`：28 条西式中文检查点（XH 1–28）
  - `references/catalog-zh.md`：31 条中文句式痕迹（ZH 1–31）
  - `references/catalog-en.md`：34 条英文检查点（EN 1–34）
  - 可读、可引用、可批判。新体系**不复制**旧编号，允许推翻旧判断。
- 旧体系的缺口（本项目要补）：
  - 只处理「偏离汉语默认值」这一类（轴一），几乎不处理「符合汉语但正好是最大公约数」这一类（轴二）；
  - 不分文体，同一判据套所有文本；
  - 无推荐机制。

## 三、核心理论假设（待检验，不预设为真）

**三类缺陷**（AI 味的三个正交来源）：

| 缺陷 | 层面 | 机制假设 |
|---|---|---|
| 甲 无对价的欧化 | 语言类型学 / 句法 | 英语骨架套在汉字上；且因无源文可忠，欧化不换来精度，只留代价 |
| 乙 语域塌缩 | 社会语言学 / 语域 | 中文高质量语料偏斜于正式书面体；模型只会一个档 |
| 丙 结构可预测 | 话语分析 / 对齐层 | RLHF 偏好长度、客观、安全；输出向连续统中点靠拢（平齐化） |

**两轴**（改法正交）：
- 轴一「纠偏」：把英语骨架换回汉语骨架 → 降低「偏离度」
- 轴二「去均值」：引入个体偏差、抬高可预测性门槛 → 降低「可预测性」

**统一假说**：AI 味 = 同语义密度下信息熵过低，读者能连续预测下一结构。

任务中请对以上假设保持批判：找得到支持就引证，找得到反例就写明反例。

## 四、输出规范（所有调研文档共同遵守）

1. **语言**：中文；术语首现给英文原文。
2. **格式**：Markdown，标题层级不超过三级，多用表格。
3. **溯源**：每个论断后标注来源（作者、年份、标题；有链接给链接）。查不到就写「未找到直接来源」，**不得编造文献、数字、页码**。
4. **分级标注**：每条结论标 `[实证]`（有语料统计/实验）/ `[学理]`（有理论依据但无量化）/ `[经验]`（实践共识，无研究支撑）。
5. **可操作**：凡描述现象，尽量给出**判定方法**（正则可捕获的、可计数的、或可人工二分的判据）与**反例边界**（什么情况下不算缺陷）。
6. **区分中英**：中文现象与英文现象分开列，不要用英文结论直接套中文。
7. **落盘**：写到指定路径，正文 3000–6000 字。不要只写在回复里。

## 五、返回给主代理的内容

≤400 字摘要 + 3–5 条最关键的数据或结论（带来源）+ 文件绝对路径。不要把全文贴回。
