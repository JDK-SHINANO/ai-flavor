# 词库收料格式 v2（语言学分层版）

> 词库不是词表，是**分层的语言事实档案**。每条词条同时回答三个问题：
> 它在语言的哪一层（level）？病从哪来（axis）？在哪些文体里合法（register）？

## 一、三维坐标

| 维度 | 取值 | 回答的问题 |
|---|---|---|
| **层 level** | 词法 / 句法 / 篇章 / 语用 / 修辞 | 问题发生在语言的哪一层 |
| **轴 axis** | 甲 / 乙 / 丙 | 病从哪来：甲 形合硬搬（跨语言迁移）／乙 语域塌缩（语料偏斜）／丙 结构可预测（对齐） |
| **域 register** | R1–R9 | 在哪一档是常态、在哪一档是病 |

三者正交。**层轴不可混**：同一个「名词化」，在词法层是后缀壳问题，在句法层是定语堆叠问题，在语用层是语域问题——收料时按它**主要**出问题的地方归一层，只归一层。

## 二、五层的定义与划界

### 词法层（morphology / lexicon）

词的内部构造与词项使用：类后缀（性／度／化／感／主义／者）、词性转换（名→动）、复数标记（们）、伪术语（无定义却像术语）、过度词（高频但不承载信息）。

**划界**：「赋能」归词法（词项滥用），不归句法；「进行了调整」归句法（动宾结构被架空），不归词法。
**判据**：问题能否靠**换一个词**解决。能，归词法。

### 句法层（syntax）

句子的结构与语序：连接词显化、被动式、定语位置与长度、零回指、时体标记、条件从句位置、句式杂糅、并列结构。

**划界**：「由于…使得」归句法（两套骨架硬拼），不归篇章；「每段以『因此』开头」归篇章（衔接模式），不归句法。
**判据**：问题能否靠**改这一句的结构**解决。能，归句法。

### 篇章层（discourse）

跨句、跨段的结构：形合衔接密度、段首主题句、元话语（metadiscourse：值得注意的是／综上所述）、逻辑标记四级、段落等长、总—分—总骨架。

**划界**：「值得注意的是」归篇章（元话语，管的是读者与命题的关系），不归修辞；「标志着新时代」归修辞（价值拔高）。
**判据**：问题是否只在**成段成篇**时才成立。是，归篇章。

### 语用层（pragmatics）

说话人与听话人的关系：句末语气词、礼貌与面子、立场表达（hedging／booster）、人称选择、称呼、语域适配。

**划界**：「句末无一个语气词」归语用（不向读者示好），不归词法；「您」的滥用归语用（过度礼貌）。
**判据**：问题是否取决于**谁对谁说**。是，归语用。

### 修辞层（rhetoric）

为效果而用的手段：比喻与意象、排比、三段式、金句收尾、意义拔高、假对比（不是 X 而是 Y）、戏剧碎片。

**划界**：「首先／其次／最后」若是结构导航，归篇章；若只为凑三段，归修辞。按**它在这段里干什么**定，不按形式定。
**判据**：删掉后**事实与论证不变，只是气势减弱**。是，归修辞。

## 三、TSV 格式（10 列，实际用 TAB 分隔）

列序：`term` `type` `level` `axis` `rule` `conf` `register_scope` `example` `source` `note`

| 列 | 取值 | 说明 |
|---|---|---|
| term | 字符串 | 词或句式。不含 TAB、换行、竖线 |
| type | `word` / `pattern` | word 是字面词；pattern 是 Python 正则（不含分隔符） |
| level | `词法` `句法` `篇章` `语用` `修辞` | 只归一层 |
| axis | `甲` `乙` `丙` | 病因 |
| rule | `J1`–`J8` / `Y1`–`Y6` / `B1`–`B9` / `NEW` | 归到已有规则；无处可归写 NEW |
| conf | `high` `mid` `low` | 见第四节 |
| register_scope | 见第五节 | **必填**，判断不了写 `待定` |
| example | 字符串 | **真实原文摘录**，≤60 字，不得自造 |
| source | URL 或文献标识 | 必填；无出处写 `[经验]` |
| note | 字符串 | 边界、例外、中文对应等 |

## 四、置信度的语言学依据

| 级 | 判据 | 例 |
|---|---|---|
| high | 正常人类写作中极罕见，出现即高度可疑 | 赋能、值得注意的是、综上所述 |
| mid | 人类也用，但 AI 用得过密或位置固定 | 因此、进行、之一 |
| low | 本身完全合法，只有配合其它迹象才有意义 | 被动句、破折号、加粗 |

**民间的「一眼 AI」清单，若无可核验的语料统计，conf 最高只给 mid**，并在 note 写「民间观察」。
本词库里能标 high 的只应有三种：语言学界公认的恶性搭配、有语料倍率的项、构词上无等价谓词的壳。

## 五、register_scope 写法

用 R1–R9 简写 + 三档判断：

| 判断 | 写法 |
|---|---|
| 该档正常，删改反出错 | `R2正常` |
| 有边界，超限即病 | `R6可容忍` |
| 明显是病 | `R7病` |

多档用空格分隔：`R2正常 R3可容忍 R7病`；全档一致的写 `全档病` 或 `全档可用`；判断不了写 `待定`。

**这一列是防误伤的主闸。**「抓手」在 R2 是术语、在 R7 是病——不填这一列，词库会把公文里的正常表达判成病灶。

## 六、四条收料纪律

1. **example 必须是真的。** 从页面原样摘，不许改写、不许自造。摘不到就不收。
2. **source 必须可点。** 给具体页面 URL 或「作者 年份 期刊 页码」，不给无定位表述。
3. **一条只归一层一轴。** 拿不准在 note 写两解，但主列只填一个。
4. **能写成「式」的不要拆成「词」。** 「首先…其次…最后」是一条正则，不是三条词条。词条是**点**，结构性规则在代码里。
