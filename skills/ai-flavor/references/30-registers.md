# 九档文体：默认值、矩阵与跨档失效

## 〇、口径

句长数据只有一处可用大样本：周义凯、刘海涛《现代汉语汉语句长分布的普遍性和特殊性》（《外语教学与研究》2023, 55(5)）——小说、新闻、社论、散文四体，整句平均 **20–25 词**，小说最短（近口语），新闻社论最长。

三点限制必须写明：

1. 单位是**词**非字（一词约 1.5 字，折 30–40 字，混用差一倍）；
2. 只覆盖四体，**其余五档无公开数据**；
3. 切分依句末点号。

下文无数据处一律标【经验】。凡引用基线，注明文体与口径。

## 一、九档小档案

### R1 学术论文

典型句长 40–70 字（限定成分多是长的主因）｜连接词容忍**高**（「因此」「然而」「就……而言」显性出现正常）｜名词化**高（正常）**｜第一人称中（单数视学科，复数「我们」通行）｜口语词极低（仅引语）｜句末语气词零｜比喻低（功能性类比可，装饰性意象禁）｜加粗限标题与术语首现，列表限方法参数材料｜金句**零容忍**｜段落 200–400 字，一段一论点。

依据：名词化与专业性正相关（Halliday 1998；朱永生 2006）【学理】；GB/T 7713.2-2022 第 5.1 条「遣词造句应符合汉语语法」【规范】、4.2.1 条题名「不应使用广义术语、夸张词语」【规范】；余为【经验】。

### R2 党政公文与工作汇报

典型句长中长，多分句排比式｜连接词容忍**高**（「据此」「为此」「按照……要求」是体式标记）｜名词化**高（正常）**｜第一人称：机构自称「我部」「我市」正常，**个人「我」是病**｜口语词零容忍（引群众语须加引号）｜语气词零｜比喻**零容忍**（已词汇化的政治隐喻「抓手」「瓶颈」「底线」算术语）｜**列表强制**，**加粗无对应物**（靠字体字号分层）｜金句允许程式收束（特此通知），禁抒情｜段落 100–250 字，一段一层次。

依据：《党政机关公文处理工作条例》第十九条「内容简洁，主题突出，观点鲜明，结构严谨，表述准确，文字精练」【规范】；GB/T 9704-2012 只管版式与序数，**不含语言条款**——用 9704 论证公文修辞属引错标准【规范】；GB/T 15834 只有「着重号」无加粗【规范】；余【经验】。

### R3 技术文档与产品说明

典型句长**短**：目标 ≤20 字，20–29 可，>40 不接受；逗号长句 ≤100 字｜连接词中（步骤间「然后」可，句句「因此」是病）｜名词化中低（术语性可，动作性「进行配置操作」是病）｜**禁「我们」指作者，用「你」指读者**｜口语词**可容忍至正常**，要求对话式｜语气词极低（「吧」可，「呢/啊」是病）｜比喻**明令禁止**｜加粗与列表**正常且常强制**（UI 元素加粗、步骤用列表）｜金句零容忍，结尾应为下一步或限制条件｜段落 ≤7 行，最佳 ≤4 行。

依据：Microsoft 简体中文风格指南 2.1 要求「使用类似于日常对话环境中的语言」；Google 开发者文档风格指南明令 Avoid figurative language, which includes metaphors【规范】。**这两条只适用技术文档，被旧体系泛化成通例，是最大的误伤源。** 句长与段落数字出社区规范【经验】。

### R4 新闻报道

典型句长整句均值属最长一档（20–25 词）｜连接词中（时间因果可，议论性「由此可见」是病）｜名词化中（「进行了……」「开展了……」式是病）｜第一人称零容忍（引语除外）｜口语词引语内正常、叙述层是病；脏话与网络缩略禁用｜语气词零容忍（引语除外）｜比喻：消息体零容忍，通讯特写可但不得含极端评价｜加粗与列表均禁｜金句零容忍（评论除外）｜段落 1–3 句，一段一事。

依据：句长【实证】周义凯、刘海涛 2023；评价词禁令【规范】新华社禁用词第 2 条；网络缩略禁令第 9 条；余【经验】。

### R5 科普

典型句长中短，**长短交替是优点**｜连接词容忍高（因果链须显性，「这意味着」）｜名词化中低（术语保留，解释句须动词化）｜第一人称正常（「我们来看」）｜口语词正常｜语气词可容忍，轻度｜比喻**正常，且是主要手段**｜加粗与列表正常｜金句可容忍，全文不超一处｜段落 80–200 字，一段一概念。

依据：全部【经验】。唯一可援引者为【学理】——读者缺背景知识，需外显逻辑与跨域类比。

### R6 自媒体与公众号

典型句长极短，大量一句成段｜连接词低，靠意合｜名词化低（高即病）｜第一人称正常，常为刚需｜口语词正常，是频道识别标志｜语气词正常｜比喻正常，但套路比喻是病｜加粗与列表正常｜金句可容忍，**每段都金句是病**｜段落 20–80 字，1–3 句。

依据：全部【经验】。与 R3 同属「正式度低」区间，机制不同：R3 便于执行，R6 建立人格。

### R7 文学散文随笔

典型句长分布最宽、**方差最大**｜连接词**低**：显性连接是败笔｜名词化低（高即病）｜第一人称正常，常为唯一视角｜口语词正常｜语气词正常｜比喻**正常，是主业**（判新不新、准不准）｜加粗与列表均禁｜金句**零容忍，最重的一档**｜段落任意，随呼吸。

依据：句长【实证】（散文、小说两档）；意合【学理】（余光中 1987）；「散文抽象名词密度 5/千字以下」为旧体系自订【经验】。

### R8 私人书信与即时消息

典型句长极短，换行代句号｜连接词极低｜名词化零容忍｜第一人称正常且高频｜口语词正常｜**句末语气词正常且高频，是刚需**｜比喻可容忍，随关系亲疏｜加粗禁，事项清单可｜金句零容忍｜段落 1–2 句。

依据：全部【经验】，语用学支撑见第四节。

### R9 译文润色

典型句长随源文，长定语常不可拆｜连接词**高（有对价）**｜名词化中高（有对价）｜第一人称随源文｜口语词随源文语域｜句末语气词需**补**（英译中须补偿语气）｜比喻保留原意象，**不得换成中文成语**｜其余随源文。

**R9 只有一条原则：欧化有对价就不是病。** 有源文可对照时，凡能在源文找到对应结构、删去会损失信息者，一律不改。

### 2.1 判据一句话

| 特征 | ○与△的分界 |
|---|---|
| 名词化 | 动作能否找到动词位。○ 本身即术语（配置、折旧）；△ 能还原而不损精度（进行测试→测试）；× 口语里绝不这么说（进行一次进食） |
| 长定语 | 数「的」：一名词前三个以上「的」，或定语超 40 字，即病 |
| 被动 | 施事测试：已知且重要却隐去＝病；未知或不必说＝正常 |
| 连接词显化 | 删掉是否会歧义。会＝保留；不会且只是提醒＝病 |
| 第一人称 | 文本是否承担个人责任。承担＝正常；硬加（「我们认为」代无主句）＝病 |
| 口语词 | 是否属说话人与听话人共享的语域。共享＝正常；跨语域借来装亲切＝病 |
| 句末语气词 | 去掉后语气是否变硬且违作者意图。是＝该留 |
| 比喻 | 喻体是否提供源域没有的信息。提供＝正常；只把抽象词换成另一抽象词＝病 |
| 三段式 | 第三项是否有增量 |
| 金句 | 删掉是否损失事实或论证 |
| 列表化 | 各项是否同质同级 |
| 加粗 | 对象是否界面元素或术语首现 |

**共同内核：信息增量测试。**「删掉是否损失信息」覆盖四条判据（金句、三段式、连接词、名词化），能替掉旧体系「正确的废话」全部子类。

| R2 比喻 × | 抓手、瓶颈、底线、闭环已词汇化，是术语。词典有独立义项则放过 |

## 三、跨档会失效的判据（13 条）

旧体系的检查点多在散文与一般写作上归纳，套到别档会反向出错。

| 旧判据 | 失效档 | 为什么 | 应改成 |
|---|---|---|---|
| 删四字格 | R1、R2、R4 | 公文四字格（统筹推进、压实责任）是体式与政治语汇 | 只在 R5–R8 判；R2 只判三连以上且无增量 |
| 去被动 | R2、R9、R1 | 规范性文件大量用受事主语句，施事不必或不能指明 | 改为施事测试 |
| 去名词化 | R1、R2、R9 | 名词化是学术公文语体的构成要素，与专业性正相关 | 分档阈值，只判「可还原且无精度损失」者 |
| 删显性连接 | R1、R2、R5、R9 | 意合是散文与消息的默认，非所有文体的默认 | 改为「删后是否歧义」 |
| 「无第一人称＝客观」 | R5–R8 全部反向 | 这四档「没有我」才是病 | 从「AI 痕迹」改为「文体特征」，判责任承担 |
| 「语气词＝不专业」 | R6、R7、R8 反向 | 自媒体与私信里零语气词是最强机器信号 | 只在 R1/R2/R4 判零容忍 |
| 「禁比喻」 | R7、R5 反向，R6 | 比喻是散文与科普的主业；Google 禁比喻只适用技术文档 | 判「喻体是否带来新信息」，按档开关 |
| 「破折号连环＝AI」 | R2、R5、R6 | GB/T 15834 4.10.3.8 允许列举分承，频次无规范 | 降级为 R1/R3 风格建议 |
| 「列表化＝AI」 | R2、R3 反向 | 公文序数强制，技术步骤必须列表 | 只在 R7 判病 |
| 「加粗＝AI」 | R3 反向 | UI 元素加粗是规范写法；公文根本不用加粗 | 只看 R6/R7 |
| 「长短句交错才自然」 | R3、R4 | R3 有 40 字硬上限，要的是**一致的短** | 节奏判据只留 R5/R6/R7 |
| 「金句收尾＝AI」 | R2 部分、R6 | 公文收束是文种程式；自媒体收尾是流量体式 | R2 判是否固定语；R6 判密度 |
| 「密度超阈值＝病」 | R1、R2 | 旧阈值上限 20/千字对学术偏低 | 分档给；R1 上限无数据，只给区间假设 |

**可操作结论：旧体系 59 条检查点里至少 13 条需要文体开关。** 不带开关直跑，在 R2 与 R7 上会出现方向相反的误判——同一段文字，在公文里被判「名词化过度」，在散文里被判「不够凝练」。

## 四、R8：私人书信与即时消息

查证结果：**无国标、无行业规定、无机构风格指南。** GB/T 15834 适用范围写「汉语的书面语」，字面覆盖即时消息，但只管标点形式，不涉语域，且无强制力。

实际语用中即时消息系统性偏离标点规范（省句末标点、换行代句号、`~` 代缓和、叹号超三个）。**这一偏离不构成错误**，因为该媒介的读者不按出版标准解读。

故 R8 判据只能建于语用学与语料观察，全标【学理】或【经验】：

- 礼貌原则（Leech）与面子理论（Brown & Levinson）：缓和语（「吧」「嘛」）承担面子工作，删掉即失礼。
- 关系距离决定语域：对上级用「您」+ 完整句，对密友用零标点 + 语气词。同一人在两处写法不同，不是不一致，是正确。
- **零语气词是这一档最强的机器信号。** 判据不是「有没有」，是「对不对人」。

## 五、标点：唯一有国标可依的部分

先分清：**国标规定用法与位置，不规定频次。** 故「破折号太多」无规范依据，只有统计与阅读经验；「破折号写成 `--`」是明确违规。

| 现象 | 规范怎么说 | 判定 |
|---|---|---|
| `--` 或单破折号 | 形式「——」，占两字（4.10.2、5.1.4） | 违规，可机器检出 |
| 一句两个以上破折号 | 4.10.3.2 允许作插入语；**无频次限制** | 无规范依据，降级为风格建议 |
| 破折号列举 | 4.10.3.8 明确允许「标示事项列举分承」 | 合规。R5/R6 正常 |
| `...` 或 `。。。` | 省略号「……」六连点，占两字（4.11.2） | 违规，可机器检出 |
| 句内套冒号 | 4.7.3.5「一般不应套用冒号」 | 违规。AI 的「**要点：** 说明」在 R1/R2 不合规 |
| 分号层级错乱 | B.1.4 并列分句不得由逗号统领 | 违规，可机器检出 |
| 加粗 | GB/T 15834 只有「着重号」（4.12），**无加粗** | 媒介特征，不在国标体系内，靠【经验】判 |

**对分档很关键**：标点判据可做硬规则（正则可捕获），修辞判据只能做软提示。混报会让人以为「破折号连环」与「`--`」同等严重，而前者只是口味。
